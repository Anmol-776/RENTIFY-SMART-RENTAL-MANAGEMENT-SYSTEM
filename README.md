# 🏠 Rentify – Smart Rental Management System

Rentify is a modern full-stack rental property management platform designed to simplify the process of discovering, listing, and managing rental properties. The platform provides a seamless experience for both property owners and tenants through an intuitive interface, secure authentication, and smart property management features.

---

### 🔐 Authentication & User Management

* User Registration & Login
* Secure Authentication System
* User Profile Management
* Session Handling

## ⚙️ Installation

### Clone Repository

```bash
git clone https://github.com/Anmol-776/RENTIFY-SMART-RENTAL-MANAGEMENT-SYSTEM.git
```

### Move to Project Folder

```bash
cd RENTIFY-SMART-RENTAL-MANAGEMENT-SYSTEM
```

### Install Dependencies

```bash
npm install
```

### Start Development Server

```bash
npm run dev
```
