# Rentify

Rentify is a modern, AI-powered rental property management platform designed for property owners, tenants, and admins.

## Features (Frontend Scope)
- **Landing Page**: Modern hero section, search functionality, property features.
- **Authentication**: Fully functional Login and Signup with Role selection (Admin, Owner, Tenant) using Trickle Database.
- **Property Listing & Search**: Advanced filters, detailed property views, AI suggestions.
- **Property Management**: Owners can create, edit, delete, and view their property listings.
- **Communication & Maintenance**: Real-time style messaging between tenants and owners. Maintenance request system with status tracking. In-app notifications.
- **Dashboards**: Separate views for Tenants, Owners, and Admins showing stats and quick links.
- **UI/UX**: Premium design utilizing Tailwind CSS, glassmorphism, responsive layouts, and elegant animations.

## Architecture
This project is built using a Multi-Page Application (MPA) architecture to keep modules isolated, performant, and clean, using React.js via CDN.
